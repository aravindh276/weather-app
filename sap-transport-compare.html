SAP System Refresh - Transport Comparison Tool

Compare STMS_IMPORT transport histories from Production and Test systems to identify transports that need re-importing after a system refresh.

How to use

  1. In SAP, go to transaction STMS_IMPORT for both Production and Test systems.
  2. Display the import history (Extras → Import History or use the import history button).
  3. Select all entries and export to a text/tab-delimited file, or copy-paste them below.
  4. The tool expects each line to contain a transport number (e.g., DEVK900123) along with optional columns like return code, date, owner, and description.
  5. Click Compare & Generate Re-Import List to get the results.
  6. Or click Load Sample Data to see a demo first.

Options

Results

Transports to Re-Import After Refresh

These transports exist only in the Test system and their main transports (for copies) are NOT in Production. These must be re-imported after the system refresh.

Transport of Copies Removed (Main Transport in Production)

These are transport of copies found only in the Test system, but their corresponding main/original transport has already been imported into Production. They do NOT need re-importing.

All Test-Only Transports (Before Filtering)

Complete list of transports found in the Test system but not in Production (before removing copies whose main is in Production).

Common Transports (In Both Systems)

Transports that exist in both Production and Test systems. These will be retained after the refresh.
